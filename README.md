# Team 4414 HighTide — RIPCURRENT 2K Interactive Desktop Wallpaper

Интерактивный живой фон для рабочего стола в разрешении **2K (2560×1440 QHD)**, созданный на основе официальных инженерных материалов и CAD-рендеров команды **FRC Team 4414 HighTide (2026 Technical Binder — RIPCURRENT)**: [https://2026.team4414.com/](https://2026.team4414.com/).

---

## 🌟 Основные возможности

1. **3D Parallax & Gyroscope View**:
   - Плавное 3D-вращение робота и элементов интерфейса в реальном времени при движении курсора мыши (на базе физики и интерполяции `Lerp`).
   - Автоматический кинематографичный режим панорамирования (**Auto-Orbit Cinema Mode**), который активируется при бездействии.

2. **Интерактивный CAD-инспектор подсистем**:
   - Переключение между полной сборкой и отдельными узлами робота в сверхвысоком разрешении (5K CAD-рендеры):
     * **Full Assembly** — полная конфигурация робота RIPCURRENT
     * **Turret** — непрерывная 360° поворотная башня (редукция 55.7:1, натяжитель flex-wheel)
     * **Shooter** — 4 мотора Kraken X44, 3″ сбалансированный маховик, независимые подвижные капюшоны
     * **Drivetrain** — компактный Swerve 25×32″ с передаточным числом 7.67:1
     * **Dye Rotor** — скоростной спиральный сериализатор мячей с анти-заклиниванием (18+ BPS)
     * **Structural Bumpers** — бамперы-монокок, совмещающие функции стенок бункера и силовой опоры
     * **Intake** — скоростной захват на 2× Kraken X60 + 1× Kraken X44
   - Интерактивные радарные точки-пины прямо на узлах робота с лазерными линиями наведения SVG.
   - Боковая панель спецификаций с инженерными данными и фотографиями изолированных компонентов.

3. **Виджеты рабочего стола в реальном времени**:
   - Большие цифровые часы (часы, минуты, секунды) и дата.
   - Имитация телеметрии робота в стиле FRC CAN-bus (напряжение батареи, загрузка шины, цикл 50 Гц).
   - Индикатор разрешения 2K (2560×1440).

4. **Аудиоэффекты и визуальные темы**:
   - Синтезатор механических серво-щелчков и футуристичных звуков через Web Audio API (без внешних аудиофайлов, кнопка включения звука в верхнем правом углу).
   - Переключение тем:
     * **Stealth Dark (по умолчанию)**: глубокий кибернетический ночной вид с неоновым циановым/бирюзовым свечением.
     * **Studio Cream**: фирменная архитектурная стилистика HighTide Binder 2026 в светлых тонах.
   - Генеративные фоновые частицы на HTML5 Canvas с эффектом созвездий и координатной сеткой.

## 🚀 Как запустить и захостить

### 🌐 Запущенный сервер (активен прямо сейчас):
- **Локальный адрес**: [http://localhost:8080](http://localhost:8080)
- **В локальной сети (LAN)**: `http://10.70.8.118:8080`
- **Публичный адрес (Интернет)**: [https://all-bananas-wait.loca.lt](https://all-bananas-wait.loca.lt) *(при первом открытии в браузере сервис запросит ввести внешний IP хоста для безопасности: `185.48.148.185`)*

Для быстрого перезапуска сервера в любое время в папке создан файл `start-server.bat`.

### Способ 1: Прямой запуск в браузере (на весь экран)
1. Откройте файл `index.html` в любом браузере (Google Chrome, Microsoft Edge, Firefox, Brave).
2. Нажмите клавишу **F11** (или иконку полного экрана в правом верхнем углу интерфейса) для перехода в полноэкранный режим 2K.

### Способ 2: Установка в качестве живого фона через Lively Wallpaper (Рекомендуется для Windows 10/11)
[Lively Wallpaper](https://rocksdanister.github.io/lively/) — бесплатное приложение с открытым исходным кодом из Microsoft Store или GitHub.
1. Установите и запустите **Lively Wallpaper**.
2. Нажмите кнопку **"Add Wallpaper"** (Добавить обои) в Lively Wallpaper.
3. Перетащите папку `team4414-interactive-wallpaper` (или выберите файл `index.html` через кнопку Browse).
4. Программа автоматически прочитает файл конфигурации `LivelyInfo.json`.
5. Нажмите **OK** — теперь интерактивный робот Team 4414 работает на вашем рабочем столе!

### Способ 3: Wallpaper Engine (Steam)
1. Откройте **Wallpaper Engine** -> **Wallpaper Editor**.
2. Выберите **"Create Wallpaper"** -> **"Web Wallpaper"** и укажите файл `index.html`.
3. Сохраните и примените обои к вашему экрану.

## 📁 Структура проекта
- `index.html` — главная разметка с HUD-оверлеем и CAD-сценой
- `styles.css` — стили 2K, переменные цвета HighTide, стекломорфизм и адаптивность
- `app.js` — движок параллакса, канвас-частиц, переключения слоев и звука
- `LivelyInfo.json` — метаданные для Lively Wallpaper
- `assets/` — загруженные локальные CAD-рендеры в сверхвысоком разрешении и логотип команды
